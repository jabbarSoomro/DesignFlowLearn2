🧠 Project Title

System Design Learning Platform (Next.js + Express API + React Flow + Prisma + Replit PostgreSQL)

💡 Build the following production-ready full-stack application on Replit:

A LeetCode-style System Design learning platform with visual system design diagrams using React Flow, XP system, badges, submissions, comments, and admin tools.
